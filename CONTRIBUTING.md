# Contributing

> [!IMPORTANT]
> **The source code and builds are not published yet.** This repository currently serves as Kraken's project information page. There is not yet a public build or contribution workflow.

Thanks for your interest in Kraken. Contribution instructions will be published when the standalone source is ready.

> [!WARNING]
> Do not submit game executables, ROMs, extracted game assets, proprietary SDK files, firmware, keys, saves, or generated game code. Only contribute material you have the right to share, and preserve relevant third-party license notices.

AI-assisted contributions must be reviewed and tested by the contributor; generated output should not be assumed correct.
